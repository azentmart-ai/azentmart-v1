# NexaBank AI — Master Streamlit Banking Dashboard

A polished, modern banking dashboard built entirely in Streamlit.

## Features
- Premium banking dashboard UI
- Sidebar navigation
- Account overview
- Balance and financial metrics
- Transactions
- Beneficiaries
- Secure transfer demo flow
- Loans
- Fraud & Risk
- Statements download
- Audit Logs
- Banking AI assistant
- Session-state based interactions

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

This version uses demo data. It is designed so the mock actions can later be replaced
with REST API calls to a NestJS/Node backend.
