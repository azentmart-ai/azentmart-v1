# AzentMart Finance AI

A standalone React + Vite frontend for the AzentMart AI Finance product.

## Run directly

```bash
npm install
npm start
```

Open:

http://localhost:5173/

## Build

```bash
npm run build
```

## Included

- Distinct Finance AI visual identity
- Exact supplied AzentMart AI logo in `public/azentmart-ai-logo.png`
- Finance command center
- Financial KPI strip
- AI workforce / six finance agents
- Interactive "Ask Finance AI" experience
- Live signal visualization
- Reporting preview
- Integrations section
- Responsive mobile layout
- No backend dependency; demo data is local

## Notes

This is a frontend prototype. The charts, insights, agents and finance answers use demo data and are ready to be connected to the Finance AI backend/API later.
